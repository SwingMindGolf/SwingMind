Zuletzt aktualisiert: Juni 2026

1. Verantwortlicher

Verantwortlicher im Sinne der DSGVO ist der Betreiber von SwingMind. Kontakt: swingmind.golf@gmail.com

2. Welche Daten wir erheben

SwingMind erhebt keine personenbezogenen Daten direkt. Die Website läuft auf GitHub Pages und speichert keine Daten auf eigenen Servern.

Folgende Daten werden lokal in deinem Browser gespeichert (localStorage):

  • Dein Golfprofil (Name, Spielseite, Körperdaten, Equipment, Ziele)
  • Dein Premium-Lizenzcode und Aktivierungs-ID

Diese Daten verlassen deinen Browser nicht und werden nicht an SwingMind übertragen. Du kannst sie jederzeit löschen indem du den Browser-Cache leerst.

3. Zahlungsabwicklung

Käufe werden über Lemon Squeezy (Lemon Squeezy Inc.) abgewickelt. Dabei werden Zahlungsdaten und E-Mail-Adresse an Lemon Squeezy übertragen. Es gilt die Datenschutzerklärung von Lemon Squeezy.

4. Lizenzvalidierung

Bei der Eingabe eines Lizenzscodes wird dieser zur Validierung an die API von Lemon Squeezy übertragen. Es werden dabei keine weiteren personenbezogenen Daten übermittelt.

5. GitHub Pages

Diese Website wird über GitHub Pages gehostet. GitHub kann dabei technische Daten wie IP-Adressen im Rahmen der Serverprotokollierung erfassen. Es gilt die Datenschutzerklärung von GitHub.

6. KI-Dienste

Die von SwingMind generierten Prompts werden von dir in externe KI-Dienste (ChatGPT, Claude, Gemini) eingegeben. SwingMind hat keinen Einfluss auf die Datenverarbeitung dieser Dienste. Es gelten die jeweiligen Datenschutzbestimmungen der Anbieter.

7. Deine Rechte

Du hast das Recht auf Auskunft, Berichtigung, Löschung und Einschränkung der Verarbeitung deiner Daten. Da SwingMind keine personenbezogenen Daten auf eigenen Servern speichert, kannst du deine lokalen Daten jederzeit selbst löschen.

Bei Fragen zum Datenschutz wende dich an: swingmind.golf@gmail.com
